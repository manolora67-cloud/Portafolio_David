Supermarket SENA Tycoon

Videojuego de simulación tipo "tycoon" pensado para

// proyectos/segutic.html

SeguTIC Soluciones

Sitio de una sola página para una empresa de
consultoría, hecho con HTML y CSS puros, sin
frameworks. El JavaScript se usa solo para lo
interactivo: menú móvil, resaltado del enlace
activo, botón "volver arriba" y validación del
formulario de contacto.
El proyecto documenta cómo conectar ese formulario
a un servicio externo (Formspree o Google Sheets)
para poder exportar los mensajes recibidos a Excel.
stack: HTML5CSS3JavaScript
demo: manolora67-cloud.github.io/SEGUTIC
